## Hva gikk bra

1. **Ren separasjon av ansvar.** Nye common-komponenter (Skeleton, Toast, InfiniteScroll, ErrorBoundary) er gjenbrukbare og uavhengige. De folger single-responsibility-prinsippet.

2. **Backend-implementasjon er minimal og korrekt.** get_similar_ads er enkel (same category, exclude self, limit 6) med kun 2 DB-queries. Endpoint er korrekt offentlig (ingen auth krevd).

3. **Infinite scroll-arkitektur.** Bruken av useInfiniteQuery fra TanStack Query med IntersectionObserver er idiomatisk og effektiv. Separat InfiniteScroll-komponent gjor det gjenbrukbart.

4. **SEO-implementasjon med generateMetadata.** Server-side metadata-generering med fetch + revalidate gir god SEO uten aa paavirke klient-ytelsen.

5. **Toast-system med Zustand.** Enkel, global tilstand uten Context-provider-nesting. Auto-dismiss og max 3 synlige toasts forhindrer UI-overfylling.
